How to Add a Document — Step by Step

1
Upload your PDF (or DOCX etc.) to the same server folder where the site files live. Note the exact filename.
2
Fill in the form above — select the category, enter the label, and paste the file URL or filename.
3
Click Generate Snippet then Copy.
4
Open documents.html in a text editor (Notepad on Windows works fine).
5
Press Ctrl+F and search for the comment matching your category. Paste the snippet directly above that comment line.
6
Find the acc-count line for that section and increase the document count by 1.
7
Save the file and upload it back to the server, replacing the old documents.html. Done.
